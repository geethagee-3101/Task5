# Task 5: Excel Data Analysis

**Internship:** Veda Technology – Data Analytics Track

## Objective
Analyze structured retail data using Microsoft Excel formulas, KPIs, summary tables, and charts.

## Work Completed
- Organized data into Raw Data, Working, and Summary sheets.
- Calculated sales, profit, quantity, and profit margin.
- Analyzed sales by category, region, segment, and month.
- Created summary tables and charts.
- Prepared findings based on the analysis.

## Tools Used
- Microsoft Excel
- Excel formulas such as SUMIFS
- Charts and data summaries

## Files
- `Veda_Task_5_Excel_Data_Analysis.xlsx` – Excel workbook
- `Veda_Task_5_Report.docx` – Task report

**Note:** The workbook uses synthetic Superstore-style sample data and formula-based summaries, not the official Sample Superstore dataset or native Excel PivotTables.
